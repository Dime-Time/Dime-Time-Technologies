# Store listing AEO (Google Play + App Store)

The AEO listing pack lives in `attached_assets/aeo-store-listings/` (README + paste-ready Play/iOS descriptions). The original `attached_assets/play-store-assets/listing-copy.txt` is the frozen v209 submission record — never edit it.

## Paste-timing rules (platform behavior, not preference)
- **Google Play bundles listing edits into any open review.** Never paste store-listing changes while a release is under review — it can slow or reset the verdict. Listing text otherwise updates any time with NO new build.
- **iOS promotional text (170 chars) is the only listing field editable any time without review or a new binary.** Description, subtitle, and keywords only change with the next version submission — keep pack ready to ride along.
- Apple search indexes ONLY name + subtitle + keyword field; the description is for humans and external AI engines reading the public apps.apple.com page. Play indexes the full description AND mines it (esp. the FAQ block) for Play's own AI answers.

## Copy rules
**Why:** fintech listing compliance (past rejections) + GEO principles (answer-first, question headers, FAQ in user language).
**How to apply:** any listing rewrite keeps the RULES APPLIED block from the README — no partner names, no bank/FDIC claims, no invented stats or "#1" claims, no dollar pricing in listings, no debt-import/crypto mentions while inactive. Open with a 2-sentence direct answer; never repeat app-name/subtitle words in the iOS keyword field.
