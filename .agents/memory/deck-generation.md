Decks are generated by python-pptx scripts kept next to their output in `attached_assets/<name>-slides/` (patent + timeline decks follow this).

**Pitch deck exception:** `dime-time-pitch-deck.pptx` has NO surviving full generator — it is a stack of 13 full-slide PNGs (`slide-01`…`slide-13`; with-ip variant adds 14–16). To update facts: regenerate only the affected slide(s) via `generate_updated_slides.py` in the same dir (render 2-slide pptx → soffice pdf → `pdftoppm -scale-to-x 1024 -scale-to-y 576` → replace PNG), then rebuild both pptx/pdf from the PNG stack (the rebuild snippet is trivial: 13.333×7.5 blank slides + full-bleed add_picture). `dime-time-ip-appendix.pptx` shares no updated slides — leave untouched. The ask slide ("Scaling Financial Automation", slide-12-ask.png) was REMOVED from both deck builds per Tim 2026-07-21 (PNG kept on disk, excluded from rebuild) — don't re-add. Current-design product screenshots live in `attached_assets/Dime-Time-App-Store-Screenshots-FINAL/iPhone-6.9/` (1290×2796, v1.0.5, the actual App Store Connect uploads) — use these for any phone imagery, never the old mockup phones. Footer page numbers are baked into old PNGs as "NN / 13"; regenerated slides keep that format for consistency (full renumber requires regenerating all slides, which lack sources).

**How to verify:** render with `soffice --headless --convert-to pdf` then `pdftoppm -png` and visually inspect every slide — text overflow/wrap bugs are invisible otherwise.

**Pitfalls learned:**
- Emoji in shapes render as tofu boxes in LibreOffice and are unreliable across viewers — use colored oval shapes + text labels instead.
- Long words in narrow shapes wrap mid-word ("MERCURY" → "MERCUR Y"); size fonts to fit the widest word.
- 40pt titles longer than ~28 chars wrap and collide with body text below; pass a smaller title size for long titles.
- Unicode ✓/✗/→ are safe; partner logos are NOT allowed (locked project rule) — names + marks only.
