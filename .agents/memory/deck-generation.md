**How to verify:** render with `soffice --headless --convert-to pdf` then `pdftoppm -png` and visually inspect every slide — text overflow/wrap bugs are invisible otherwise.

**Pitfalls learned:**
- Emoji in shapes render as tofu boxes in LibreOffice and are unreliable across viewers — use colored oval shapes + text labels instead.
- Long words in narrow shapes wrap mid-word ("MERCURY" → "MERCUR Y"); size fonts to fit the widest word.
- 40pt titles longer than ~28 chars wrap and collide with body text below; pass a smaller title size for long titles.
- Unicode ✓/✗/→ are safe; partner logos are NOT allowed (locked project rule) — names + marks only.
