# Founder PII policy

Dossier/journal/profile files were deleted 2026-07-19, before the project was shared with outside engineers/investors.

**Rule:** Never store founder personal, family, or financial details in any project file (including memory topic files). Communication preferences live in `replit.md`.

**Why:** The repl is shared with third parties (engineers, investors) and forks/exports copy every file; anything written down leaks beyond the founder's control.

**How to apply:** If a task needs personal context (pitch narrative, bios, finances), pull it from user-owned `attached_assets` at request time and copy nothing into memory or tracked files.
