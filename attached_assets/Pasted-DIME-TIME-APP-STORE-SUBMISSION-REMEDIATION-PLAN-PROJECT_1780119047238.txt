========================================================
IMPORTANT GOOGLE ANALYTICS CLARIFICATION

Google Analytics is intentionally connected to the public Dime Time website.

DO NOT remove Google Analytics from the website.

DO NOT remove Google Analytics from browser-based users.

Google Analytics should continue functioning normally when users visit:

https://dime-time.com

The issue is that Google Analytics currently loads inside the Capacitor iOS WebView.

Apple may treat this as analytics/tracking collection occurring inside the native application.

For App Store approval:

* Keep Google Analytics enabled on the public website.
* Disable Google Analytics when running inside the native Capacitor app.
* Prevent GA scripts from loading in native iOS builds.
* No ATT implementation is desired for Version 1.

IMPLEMENTATION GOAL:

if (Capacitor.isNativePlatform()) {
// Do not initialize Google Analytics
} else {
// Initialize Google Analytics normally
}

Expected Result:

WEB:
✓ Google Analytics enabled

IOS APP:
✓ Google Analytics disabled
