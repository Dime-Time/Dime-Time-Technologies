WHAT THE EXCEPTION MAY REVEAL

Possible exception categories include:

1. Resources$NotFoundException
   Likely meaning:
   - Missing theme
   - Missing drawable
   - Missing color
   - Missing splash-screen resource
   - Device-specific resource packaging issue

2. ClassNotFoundException
   Likely meaning:
   - Activity or application class missing
   - Incorrect dependency packaging
   - Incorrect generated manifest reference

3. NoClassDefFoundError
   Likely meaning:
   - Required runtime dependency omitted
   - Dependency-version incompatibility
   - Class referenced by a plugin is unavailable

4. IllegalStateException
   Likely meaning:
   - Splash-screen initialization problem
   - WebView initialization problem
   - Capacitor Bridge startup problem
   - Invalid lifecycle or theme configuration

5. UnsatisfiedLinkError
   Likely meaning:
   - ABI-specific native library missing
   - Incorrect split-APK delivery
   - Native dependency incompatible with arm64
   - Native library incompatible with the emulator page size

6. SecurityException
   Likely meaning:
   - Manifest component restriction
   - Exported-component issue
   - Platform security restriction
   - Permission or intent-filter problem

7. WebView provider exception
   Likely meaning:
   - Android System WebView problem
   - Chrome/WebView provider incompatibility
   - Emulator system-image problem

A Play-delivered Android App Bundle can behave differently from a locally installed universal APK because Google Play generates optimized split APKs for each device.

However:

- AAB splitting is standard behavior.
- Play App Signing normally does not cause a successfully installed app to crash at launch.
- Signing problems usually prevent installation or updating.
- Dime Time currently has no obvious custom native library that makes ABI splitting the leading theory.
- The fact that the crash occurs on both a 16 KB preview emulator and a stable standard-page-size emulator makes the experimental 16 KB image an unlikely sole cause.
