PROJECT: DIME TIME — VALUATION OVERVIEW (INTERNAL)

STAGE:
Pre-seed / early-stage fintech (post-build, pre-scale)

CURRENT STATUS:
- Functional iOS app live on TestFlight (v1.0.1)
- Backend deployed (production environment active)
- Plaid integrated in production (bank linking + transaction ingestion)
- Mercury integrated for fund routing and ACH workflows
- Coinbase integration (demo mode for crypto allocation)
- Core financial flows operational (round-ups → allocation → transfer lifecycle)

PRODUCT CLASSIFICATION:
Consumer fintech platform focused on automated microallocation of funds toward:
1) Debt reduction
2) Asset accumulation (crypto)

CORE INNOVATION:
“Dynamic Dual-Split Round-Up Microallocation System”
- Programmable allocation of transaction round-ups across multiple financial endpoints
- Supports fractional, percentage-based, and dynamic allocation logic
- Designed for behavioral automation (no manual user intervention required)
