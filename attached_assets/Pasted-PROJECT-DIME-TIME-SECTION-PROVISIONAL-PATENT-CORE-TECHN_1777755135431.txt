PROJECT: DIME TIME
SECTION: PROVISIONAL PATENT — CORE TECHNOLOGY
TITLE: Dynamic Dual-Split and Multi-Destination Round-Up Microallocation System

────────────────────────────────────────────
1. FIELD OF INVENTION
────────────────────────────────────────────

The present invention relates to financial technology (fintech), specifically to systems and methods for automated microallocation of transaction round-up amounts across multiple financial destinations, including but not limited to debt repayment and digital asset acquisition.

────────────────────────────────────────────
2. PROBLEM STATEMENT
────────────────────────────────────────────

Existing round-up platforms suffer from:
• Single-destination allocation (savings OR debt OR investing)
• Static allocation models (no flexibility)
• Lack of real-time execution per transaction
• No intelligent or dynamic allocation capabilities

There is no system that:
→ Splits round-ups across multiple destinations simultaneously
→ Allows continuous allocation ratios (0%–100%)
→ Executes allocations in real-time per transaction
→ Supports programmable or adaptive allocation logic

5. ALLOCATION VECTOR MODEL
────────────────────────────────────────────

Allocation defined as:

A = (d₁, d₂, d₃, … dₙ)

Where:
• dₙ represents % allocation to each destination
• Σ dₙ = 100%

Examples:
• (100, 0) → Full Debt
• (80, 20) → Debt + Crypto
• (50, 30, 20) → Multi-destination future model

This creates a **continuous claim space**, preventing design-arounds.
