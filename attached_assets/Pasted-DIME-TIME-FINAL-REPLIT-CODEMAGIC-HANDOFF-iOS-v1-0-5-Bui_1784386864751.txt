================================================================
RELEASE GOAL
================================================================

Build 207 is the production bank-linking reliability release.

The headline change is support for returning users to Dime Time after they
authenticate with an OAuth bank such as Chase.

Before this release, a user could authenticate at the bank and become stranded
in Safari instead of returning to Dime Time.

Build 207 combines:

1. Plaid OAuth Universal Links
2. OAuth session-resume handling
3. Friendly interrupted-connection recovery
4. Slide-out menu/navigation correction
5. Round-up funding-account selection
6. Plaid Liabilities graceful gating
7. Honest ACH payment statuses
8. Debt-chart corrections
9. Contact-form and email-delivery fixes
10. Password-reset security and failure handling
11. Stripe payout-routing configuration correction
12. CI safeguards for entitlements and build numbers

Users can select which eligible linked bank account funds their round-ups.

Location:

Settings > Funding account selector

Server safeguards:

- The app must not silently fall back to another bank
- The pay button becomes unavailable
- The user is told to select or reconnect an account in Settings
- The server independently blocks payment execution

- Returned
