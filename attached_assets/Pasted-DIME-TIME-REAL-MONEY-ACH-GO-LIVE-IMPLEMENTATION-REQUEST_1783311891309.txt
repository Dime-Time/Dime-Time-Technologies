Verify live Stripe webhook endpoint:

POST /api/stripe/webhook

Must use raw body signature verification with STRIPE_WEBHOOK_SECRET.

Handle these events:
- payment_intent.processing
- payment_intent.succeeded
- payment_intent.payment_failed
- payment_intent.canceled
- charge.dispute.created
- charge.dispute.closed

Required webhook behavior:
- Deduplicate events using stripe event id
- Find internal transfer by metadata.transferId or paymentIntentId
- Update internal transfer status:
  - processing → processing
  - succeeded → settled/succeeded
  - payment_failed → failed
  - canceled → canceled
  - dispute → disputed
- Store failure reason when available
- Never create duplicate ledger credits/debits
- Never rely on frontend success state for final settlement
